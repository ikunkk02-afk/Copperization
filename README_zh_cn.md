# Copperization（万物铜化）

Copperization 是一个面向 Minecraft 26.2 的 Fabric 模组。它把原版铜的设计语言扩展到生物和常见建筑方块，并围绕“渐进铜化—冻结成雕像—搬运—氧化与保养”形成完整玩法。

## 核心玩法

- **铜化附魔**：仅支持原版铜剑，共三级；有效近战攻击分别增加 15%、22%、30% 铜化值。
- **生物铜化**：铜斑分阶段扩散，同时逐步降低移动与攻击能力。
- **铜雕像**：铜化达到 100% 后，生物停止 AI、寻路、攻击和移动，并保留实体类型、名称、年龄、变种、装备与通用姿态数据。
- **氧化、上蜡与刮除**：雕像在服务端低频氧化；蜂巢锁定当前阶段；斧头优先去蜡，再逐级恢复氧化状态。
- **雕像搬运**：用镐拆下雕像得到一个通用铜雕像物品，右键方块表面可重新放置并恢复保存的数据。
- **铜化法杖**：带 256 点耐久与 20 tick 冷却，可将受支持的建筑方块铜化。
- **铜化方块**：11 个安全建筑方块家族，每个包含四个氧化阶段和四个上蜡变体。

## 运行要求

- Minecraft Java Edition 26.2
- Fabric Loader 0.19.3 或兼容的新版本
- Fabric API 0.158.0+26.2 或兼容的新版本
- Java 25

模组不需要 GeckoLib 或 Player Animation Library。多人游戏中，服务端和所有客户端都需要安装。

## 安装

1. 为 Minecraft 26.2 安装 Fabric Loader。
2. 将 Fabric API 与 Copperization 的 jar 放入游戏实例的 `mods` 文件夹。
3. 使用 Fabric 配置启动游戏。

## 游玩方法

通过正常附魔系统获得“铜化”，并将其用于铜剑。其他材质的剑不能正常获得此附魔。攻击符合条件的生物，铜化达到 100% 后会生成保持原实体数据的铜雕像。

对雕像使用蜂巢可以上蜡；使用斧头会优先去蜡，否则向前刮除一级氧化；使用镐会将雕像安全打包成一个物品。雕像物品的名称和提示会显示实体类型、氧化阶段与上蜡状态。

铜化法杖配方为竖向排列的铜锭、紫水晶碎片和烈焰棒。第一版支持：

- 石头、圆石、石砖
- 深板岩、深板岩圆石、深板岩砖
- 红砖、黑石、磨制黑石
- 末地石、下界砖块

箱子、熔炉、红石元件、门、床、活塞、传送门和其他复杂方块不会被法杖修改。

## 当前限制

- 玩家、末影龙、凋灵、死亡实体和无法安全序列化的实体不会铜化。
- 乘客与拴绳关系不会写入雕像物品；拆卸时会安全分离。
- 通用姿态冻结覆盖位置、身体/头部方向、俯仰、实体姿态、肢体动画、攻击动画、年龄动画与手部使用状态；少数实体专属骨骼不保证逐帧冻结。
- 铜层使用稳定的四阶段 UV 遮罩。它保留原模型和纹理细节，但在特殊 UV 模型上只能近似表现从下向上的侵蚀。
- 0.1.0 只支持上述 11 类安全完整方块。

## 从源码构建

安装 Java 25 后执行：

```text
gradlew.bat runDatagen
gradlew.bat build
gradlew.bat runClientGameTest
```

构建产物位于 `build/libs/`。`build` 会自动运行 JUnit 和服务端 GameTest。
