# Changelog

All notable changes to Copperization are documented here.

## 0.1.0

- Added the three-level Copperization enchantment for copper swords.
- Added persistent, server-authoritative copperization state and synchronized staged debuffs for eligible living entities.
- Added a generic copper overlay render layer with four irregular masks and oxidation tinting.
- Added copper statues with AI/tick freezing and stable generic pose capture.
- Added one component-backed Copper Statue item that preserves entity data and supports atomic pickup and placement.
- Added statue oxidation, honeycomb waxing, axe wax removal, and staged scraping.
- Added the durable Copperization Wand and its copper/amethyst/blaze-rod recipe.
- Added 11 copperizable building-block families with 88 total weathering and waxed variants.
- Added English and Simplified Chinese translations, recipes, tags, loot tables, block states, item definitions, models, textures, and icon.
- Added JUnit, dedicated-server GameTests, a client world smoke test, and GitHub Actions build reporting.
